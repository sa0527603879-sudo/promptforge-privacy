# חיבור קלוד ל‑REAPER — ההתקנה בפקודה אחת

התיקייה הזאת מכילה את מה שהמדריך ביקש ממך לעשות ביד. הסקריפטים עושים את זה במקומך.

## מה שצריך פעם אחת, לפני הכול

1. **להתקין REAPER** — <https://www.reaper.fm/download.php>
   ואז **לפתוח אותו פעם אחת ולסגור**. זה מה שיוצר את תיקיית ההגדרות שהסקריפט מחפש.
2. **להתקין Claude Desktop** — <https://claude.ai/download>

## ההתקנה

### Windows

פותחים PowerShell בתיקייה הזאת ומדביקים:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1
```

### macOS

פותחים Terminal בתיקייה הזאת ומדביקים:

```bash
bash setup-macos.sh
```

## מה הסקריפט עושה — חמישה שלבים

| # | מה |
|---|---|
| 1 | מתקין את `uv` |
| 2 | מעתיק את סקריפט הגשר לתיקיית REAPER |
| 3 | מחבר אותו ל‑`__startup.lua` — **כך הגשר נטען לבד בכל פתיחה של REAPER** |
| 4 | רושם את השרת בקובץ ההגדרות של Claude Desktop |
| 5 | סוגר ופותח את Claude Desktop כדי שיקרא את ההגדרות |

שלב 3 הוא זה שחוסך לך את הכאב הכי גדול: בלעדיו היית צריך ללכת ל‑`Actions →
Show action list → Load ReaScript` **בכל פעם מחדש** שאתה פותח את REAPER.

אם כבר יש לך `__startup.lua` משלך — הוא נשמר, והבלוק שלנו מתווסף בסוף.
אותו דבר עם קובץ ההגדרות של קלוד: שרתים אחרים שמוגדרים שם נשארים.
כל קובץ שנוגעים בו מגובה קודם ל‑`.backup`. אפשר להריץ שוב בלי נזק.

**דגלים:**
`-SkipClaudeRestart` (ווינדוס) או `SKIP_CLAUDE_RESTART=1` (מאק) — לא לגעת ב‑Claude Desktop.
`-ReaperScripts "D:\REAPER\Scripts"` או `REAPER_SCRIPTS=...` — ל‑REAPER נייד.

## מה נשאר לך אחרי שהסקריפט רץ

**לפתוח את REAPER.** זהו.

בקונסולה אמור להופיע `REAPER MCP Bridge (File-based, Full API) started`,
ואז בקלוד: «כמה טראקים יש לי בפרויקט ב‑REAPER?»

> אחרי כל עדכון של החבילה — מריצים את הסקריפט שוב. הגשר והשרת חייבים להיות
> באותה גרסה, אחרת הכלים נכשלים **בשקט**.

## חבילת ה‑MIDI להתחלה

`midi/` — ארבעה לופים של 8 תיבות, **130 BPM, לה מינור**.

המספרים האלה לא שרירותיים: הם נלקחו מהניתוח של **Bicep — "Opal"**
(‏130 BPM, לה מינור, Camelot 8A, danceability 0.80), שזה בדיוק הסאונד
המלודי‑האוס המקצועי שאתה מכוון אליו.

| קובץ | מה זה |
|---|---|
| `chords_Am_130.mid` | Am9 → Fmaj9 → Cmaj7 → G |
| `bass_Am_130.mid` | בס על האוף‑ביט, משאיר מקום לקיק |
| `arp_Am_130.mid` | ארפג׳יו בשמיניות‑עשרה על שתי אוקטבות |
| `drums_130.mid` | קיק על כל רבע, מחיאה על 2 ו‑4, הייהאט על האוף |

גוררים ישר לתוך REAPER. הקצב נמצא בתוך הקבצים, אז הפרויקט יתיישר לבד.

לשנות סולם או טמפו: עורכים את `BPM` / `PROGRESSION` בראש `make_midi.py`
ומריצים `python3 make_midi.py`.

## מה נבדק בפועל

- **סקריפט המאק** הורץ מקצה לקצה: התקנה נקייה, `__startup.lua` קיים של המשתמש
  (נשמר), הרצה חוזרת (בלי כפילות), מיזוג לקובץ הגדרות קיים, JSON פגום
  (נכשל בלי להרוס), ו‑REAPER לא מותקן.
- **סקריפט הווינדוס** הורץ מול PowerShell 7.4.6 באותם מקרים.
  ‏PowerShell 5.1 — ברירת המחדל בווינדוס — **לא נבדק**, אך אין בסקריפט
  תחביר שדורש 7.
- **קוד ה‑Lua** של `__startup.lua` עבר בדיקת תחביר בקומפיילר Lua אמיתי,
  גם לבד וגם משורשר לקובץ קיים.
- **קבצי ה‑MIDI** נבדקו בפרסר חיצוני (`mido`): טמפו נכון, כל `note_on` עם
  `note_off` תואם, התופים על ערוץ 10.
